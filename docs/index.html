Platform Features

Everything you need to
run a language academy

From content creation to billing, Langopia handles every aspect of modern language education.

Course Builder

Create structured courses with modules, lessons, and AI-generated exercises. Organize content by language and CEFR level.

Media Library

Upload PDFs, presentations, images, and audio. AI automatically extracts text, generates embeddings, and creates searchable content.

Student Management

Invite students, manage enrollments, track attendance, and monitor progress. Soft-delete ensures data is never lost.

Exercise Engine

20+ exercise types including fill-in-the-blank, guided conversations, podcasts, and stories. AI generates exercises from media content.

Recording & Egress

Automatic LiveKit Egress recordings stored in S3/MinIO. Post-class pipeline processes audio for AI analysis.

Stripe Billing

Built-in Stripe Connect integration. Academies collect student payments with automatic 2% platform fee. Subscription management included.
